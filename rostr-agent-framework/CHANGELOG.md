## [0.1.0] - 2026-04-12

### Added
- Initial release of Rostr Agent Framework
- PAL (Prompt Abstraction Layer) with intent extraction, context injection, and semantic enhancement
- RAG DAL (Dynamic Acquisition Layer) with 3-tier source credibility hierarchy
- NPAO (Navigate, Prioritize, Allocate, Orchestrate) with 5D framework
- Rostr Hub central platform with agent registry and state management
- Standard agent library (Builder, Researcher)
- CLI tool for workspace management
- Python SDK for programmatic usage
- Comprehensive documentation and examples
- MIT License

### Components
- `rostr.core` - Hub, registry, state management, event bus
- `rostr.pal` - Prompt compilation and routing
- `rostr.ragdal` - Knowledge retrieval pipeline
- `rostr.npao` - Task orchestration engine
- `rostr.agents` - Standard agent library
- `cli` - Command-line interface
