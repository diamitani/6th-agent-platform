## 4. Page-by-Page Copy

### Homepage

**Hero:**
```
Describe what you need.
Get a working agent.
```
Sub: "Type what you want an agent to do. We build it. System prompt, triggers, behavior.
Ready to chat in one click."

**How it works (3 steps):**
```
1. Describe your agent
What should it do? Who is it for? Write it in plain English.

2. We build it
Our compiler reads your description and generates the complete agent —
system prompt, triggers, behavior rules, output format.

3. Chat with it
Your agent is live. Toggle between free local AI (Ollama) or cloud (Gemini).
```

**CTA:**
"Build your first agent free" (primary)
"See how it works" (secondary)

### Pricing Page

**Headline:**
"From walk-on to starter. Pick your minutes."

**Tiers:**
- Free: "Get in the game"
- Core: "Earn your minutes"
- Pro: "Sixth man of the year"

**Free tier CTA:** "Start free"
**Paid tier CTA:** "Start free trial"

### About / How it works page

**Headline:**
"Natural language in. Agent manifest out."

**Sub:**
"Here's what happens when you describe an agent."

**The pipeline (unnamed):**
```
1. Your description → We read it
We extract what domain your agent works in (Sales, Marketing, Operations, etc.),
what constraints apply, what triggers activate it, and what output format it needs.

2. We add context
Your org's identity, ICP, and knowledge base are injected automatically.
Every agent knows who you are and who you serve.

3. We sharpen it
Vague instructions become precise rules. "Reach out to people" becomes
"Send 30 personalized messages per day across Instagram, LinkedIn, and Twitter."
Missing steps get added. Edge cases get handled.

4. We build the agent
System prompt. Trigger words. Behavior profile. Completion criteria.
All compiled into a working agent ready to chat.

5. You get the keys
Your agent is on your roster. Start talking immediately.
Edit it, refine it, or build more.
```

### Chat page (empty state)

"Describe what you need. Or pick an agent from your roster to get started."

### Agent builder page

**Prompt placeholder:**
"I need an agent that sends 30 personalized DMs per day on Instagram, LinkedIn, and Twitter. It should follow a 3-touch sequence and require my approval before sending."

## 8. Brand Names & Terms

| Term | Use |
|------|-----|
| **6thAgent** | Always camelCase. "6thAgent" not "6th Agent" or "6th agent" |
| **PAL** | Internal only. Docs, How it works, Technical. Never in marketing copy. |
| **Agent** | What users build. Not "bot", "assistant", or "AI worker". |
| **Roster** | The user's collection of agents. Like a sports team roster. |
| **Compiler** | What we do. Not "generator", "builder", or "creator". |
| **Describe** | What users do. Not "prompt", "configure", or "set up". |
