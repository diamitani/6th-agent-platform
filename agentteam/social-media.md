## Platform Formats

### LinkedIn (3x/week)

**Format options:**

**Option A — The Insight Post**
```
[Bold opening line — no "I" at start]

[2-3 lines of context — what happened / what you observed]

[The insight — what this means]

[1-line takeaway or question]
```

**Option B — The List Post**
```
[Bold claim]

[Short setup — 2 lines]

[List — 5-7 items, each punchy]

[Closing line — what to do with this]
```

**Option C — The Story Post**
```
[Hook — first line must make them stop scrolling]

[The story — what happened, in plain English]

[What you learned]

[Ask or CTA]
```

**LinkedIn Rules:**
- First line is everything. Rewrite it 3x.
- Never use hashtags mid-post
- 3 hashtags max at the end (or none)
- No external links in post body (put in comments)
- Line breaks every 1-2 sentences (mobile reads vertical)

---

### Instagram (Daily)

**Content Types:**

| Type | Format | Cadence |
|------|--------|---------|
| Carousel | 5–10 slides, tip/framework | 3x/week |
| Reel | 15–30 sec, POV or reaction | 2x/week |
| Story | Behind-the-scenes, polls | Daily |
| Single Image | Quote, stat, visual proof | 2x/week |

**Caption Formula:**
```
Line 1: Hook (1 line, stop the scroll)
Line 2-3: Setup (what this is about)
Body: The content (parallel to the image/reel)
CTA: "Save this." / "Drop a 🔥 if this hit." / "Link in bio."
Hashtags: 5-10, in first comment
```
