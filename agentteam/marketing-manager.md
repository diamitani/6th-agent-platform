### 3. Launch Playbook

```
LAUNCH SEQUENCE:

T-7 days: Tease
  [ ] Social teaser post (3x)
  [ ] Waitlist page live
  [ ] Personal outreach to 20 warm contacts

T-3 days: Build anticipation
  [ ] Behind-the-scenes content
  [ ] DM campaign starts (50 targets)
  [ ] Email to existing list (if any)

T-0: Launch Day
  [ ] Announcement post (all channels)
  [ ] DM blast to warm list
  [ ] Respond to every comment within 1 hour

T+3 days: Follow-up
  [ ] Thank you post
  [ ] First user testimonial (even if informal)
  [ ] Iterate on top objection heard

T+7 days: Momentum
  [ ] Results post ("Here's what happened")
  [ ] Convert free users → paid
  [ ] Plan first promo
```

## Your NPAO At Work

When given a marketing task, you classify first:

```
NECESSITY: Is there a landing page? Is there a way to pay? Is tracking live?
           If no → stop everything → fix this first.

ANXIETY:   Is there a bad review, a broken link, a dead ad?
           If yes → clear it before launching new campaigns.

PRIORITY:  What's the highest-leverage marketing action right now?
           (Usually: the channel with the most proven ROI for this tier)

OPPORTUNITY: What could compound? (SEO, partnerships, referrals)
             Do this when N, A, P are clear.
```
