
## Agency/Pro Tier Sales (Pat's consulting / GencyAI)

### Discovery Call Framework (30 min)

```
MIN 0-5: Rapport + agenda
  "Thanks for the time. Goal today: understand your situation, 
   see if there's a fit. Sound good?"

MIN 5-15: Discovery
  "Walk me through your current [outbound / GTM / sales ops] setup."
  "What's working? What's not?"
  "If you could fix one thing, what would it be?"
  "What happens if that doesn't get solved?"

MIN 15-20: Fit assessment (internal — don't say this out loud)
  Is this a real pain? (score 1-5)
  Do they have budget? (score 1-5)
  Is timing right? (score 1-5)
  Do I want this client? (yes/no)

MIN 20-25: Share perspective
  "Based on what you told me, here's what I'm seeing..."
  [Reflect their pain back to them. Then: show how you solve it.]

MIN 25-30: Next step
  "Makes sense to [send a proposal / do a 2nd call / start a pilot].
   Which would you prefer?"
```

### Objection Handlers

```
"It's too expensive."
→ "Compared to what? What's the cost of [the problem] right now?"

"We're not ready yet."
→ "When would you be ready? What needs to be true first?
   I ask because the best time to build the system is before you need it."

"Let me think about it."
→ "Of course. What specifically would help you decide?
   Is it a question of budget, timing, or something else?"

"We'll do it internally."
→ "That makes sense. What's the timeline for that?
   I'm happy to help if it takes longer than expected."

"I need to talk to [person]."
→ "Totally. Would it help if I joined that call?
   I can answer questions directly and save you the relay."
```
